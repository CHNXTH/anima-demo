# Anima Demo

Interactive web demo. Source, images and the FY font are stored separately.

## Open locally

Download this repository as a ZIP, extract it, and open `site/index.html` in a browser. Keep the `assets` folder next to `index.html`.

The demo supports touch feedback, a separate startled response, long-press dragging, driving-state restrictions and navigation avoidance. Music, navigation and vehicle state are local simulations.

GitHub Pages publishes the `site` directory through the deployment workflow.

Online demo: https://chnxth.github.io/anima-demo/
